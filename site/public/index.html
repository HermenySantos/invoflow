Perguntas

O Invoflow substitui o contabilista?

Não. O Invoflow não substitui o contabilista. O pack organiza informação para quem faz a contabilidade. Não é aconselhamento fiscal.

A estimativa de IVA é oficial?

Não. É uma estimativa. Este valor ignora o IVA das vendas. Nada é enviado à Autoridade Tributária.

Onde ficam os dados deste formulário?

Com o endpoint vazio, o formulário não é enviado e não fica guardado. Quando configurar o endpoint, mantenha esse armazenamento na União Europeia. Os detalhes estão na página de privacidade.
